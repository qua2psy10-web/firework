# 星降る夜

60秒のSVG花火アニメーション。58発。尺玉から始まり、徐々に大輪へ、42秒からスターマイン、最後は黄金の柳が消えて終了します。

## 音付きで見る
このフォルダで `python3 -m http.server 8765` を実行し、ブラウザで http://localhost:8765 を開いて「音付きで再生」を押してください。音声はWeb Audioで合成します。通信・APIキー・音源購入は不要です。再生・一時停止・シーク・音量・リプレイに対応しています。別のタブへ移動すると一時停止します。

`fireworks.svg` は単独でもブラウザで60秒の映像を再生できます（音声なし）。画像として埋め込む場合も音声は含まれません。音付き再生は `index.html` を使ってください。実際の尺玉の寸法を再現する物理シミュレーションではなく、演出表現です。

`build.py` がSVGと打ち上げスケジュールを再生成します。

`花火・音付き.html` は映像とプログラムを内包した単一ファイル版です。ブラウザで開くだけで再生でき、サーバーは不要です。
